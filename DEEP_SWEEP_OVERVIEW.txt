VascoApp Deep Sweep Overview (No Changes Applied)
=================================================

Scope
-----
- Deep sweep focused on routing, navigation targets, modal registration,
  and missing screens.
- Findings are from static review only; no code edits made.


High Severity
-------------
1) Broken route: /contractor/jobs
   - Linked in: app/(tabs)/hub/index.tsx
   - There is no app/contractor/jobs.tsx
   - Existing contractor job detail is app/contractor/job/[id].tsx
   - Impact: navigation 404

2) Broken route: /hub/documents
   - Linked in: app/(tabs)/hub/index.tsx
   - There is no app/hub/documents.tsx
   - The documents screen exists under app/(tabs)/hub/documents.tsx
   - Impact: navigation resolves to wrong tree or 404

3) Duplicate /hub route trees (routing conflict risk)
   - app/hub/* and app/(tabs)/hub/*
   - Both map to /hub/* routes
   - Impact: ambiguous navigation behavior and unexpected screen resolution


Medium Severity
--------------
4) Two parallel contractor experiences
   - app/(contractor) (tabbed)
   - app/contractor (stack)
   - Links jump between them
   - Impact: inconsistent back behavior and context switches


Low Severity
------------
5) Many router.push calls use "as any"
   - Masks route mistakes at compile time
   - Not a runtime error by itself but makes navigation regressions easier

Additional Findings (Deeper Sweep)
---------------------------------

High Severity
-------------
6) Broken route: /contractor/complete-job/:jobId
   - Linked in: src/components/dashboards/ContractorDashboard.tsx
   - Screen exists as app/contractor/complete-job.tsx (no dynamic segment)
   - Impact: navigation 404 for job completion flow

7) Route mismatch: /contractor/decisions
   - Linked in: src/components/dashboards/ContractorDashboard.tsx
   - Screen exists at app/(contractor)/decisions.tsx (tabbed group)
   - Impact: navigation 404 or wrong stack context

8) Broken route: /contractor/jobs (multiple references)
   - Linked in: src/components/intelligence/AIRecommendations.tsx
             and app/(tabs)/hub/index.tsx
   - No app/contractor/jobs.tsx exists
   - Impact: navigation 404

9) Broken route: /hub/documents
   - Linked in: app/(tabs)/hub/index.tsx
   - Exists only under app/(tabs)/hub/documents.tsx
   - Impact: ambiguous routing due to duplicate /hub trees

Medium Severity
--------------
10) Ambiguous /hub routing (duplicate trees)
    - app/hub/* and app/(tabs)/hub/*
    - Multiple dashboard links target /hub/* paths
    - Impact: uncertain navigation target; may resolve to unintended tree

11) Cross-context navigation (tabs <-> stack)
    - Enterprise dashboards route to /contractor/* screens
    - Contractor tabs are under app/(contractor) while many tools live under app/contractor
    - Impact: inconsistent back stack and UI context


Suggested Fixes (Pending Approval)
----------------------------------
- Align routes in hub and contractor links to existing screens.
- Consolidate one /hub tree (either tabs or root) to avoid conflicts.
- Decide on a single contractor navigation model (tabbed vs stack).
- Remove "as any" where possible to restore typed navigation safety.
